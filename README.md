# Umaiya Akter — Portfolio

A personal portfolio showcasing selected projects, technical interests, and contact information.

## Overview

This is a responsive, single-page portfolio built with semantic HTML, CSS, and a small amount of vanilla JavaScript. The visual direction combines an editorial serif aesthetic with a warm, understated color palette.

## Sections

- **Home** — introduction and primary links
- **About** — background and interests
- **Selected Work** — academic and personal projects
- **Capabilities** — programming, AI/data, web, and tools
- **Journey** — education and ongoing learning
- **Contact** — email and professional links

## Run locally

No build tools or package installation are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Umaiya22/portfolio.git
   ```
2. Open the repository folder.
3. Open `index.html` in a browser.

You can also use the VS Code Live Server extension for local preview.

## Update your portrait

The page currently looks for an image named `umaiya.jpg` in the repository root. Add your own portrait with that exact filename, or update the image path in `index.html`. If the image is missing, the page displays a text fallback.

## Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Customization checklist

- Keep project descriptions accurate and link each project to its correct repository.
- Add a portrait only if you are comfortable making it public.
- Review the email address and external links before publishing.
- Keep skill labels aligned with tools you can confidently discuss.
- Never add API keys, passwords, or other secrets to this repository.
